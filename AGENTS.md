# Project Rules and Instructions

## Git Push Target
- **Primary Repository:** [https://github.com/santhoshm13/SAKHI/](https://github.com/santhoshm13/SAKHI/)
- Whenever committing and pushing changes in this project, **always push to `https://github.com/santhoshm13/SAKHI/`** (remote `santhosh` / push URL of `origin`).
- Never push exclusively to any other repository. Both `origin` and `santhosh` push targets are configured to `https://github.com/santhoshm13/SAKHI.git`.
